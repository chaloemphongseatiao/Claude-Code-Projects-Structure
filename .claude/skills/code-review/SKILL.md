# Skill: Code Review

## Purpose
Perform structured code reviews focusing on correctness, security, performance, and maintainability.

## Usage
Invoke this skill when reviewing pull requests or code changes.

## Checklist
- [ ] Logic correctness
- [ ] Security vulnerabilities (OWASP Top 10)
- [ ] Performance considerations
- [ ] Code readability and naming
- [ ] Test coverage
- [ ] Documentation
