# Prompt: Code Review

Review the following code and provide structured feedback.

## Instructions
1. Check for correctness — does the logic do what it claims?
2. Check for security vulnerabilities (OWASP Top 10)
3. Check for performance issues (N+1, unnecessary loops, large allocations)
4. Check naming clarity and readability
5. Suggest improvements without rewriting working code

## Output format
- **Summary:** one-line overall assessment
- **Issues:** list only real problems, not style preferences
- **Suggestions:** optional improvements, clearly marked as non-blocking
