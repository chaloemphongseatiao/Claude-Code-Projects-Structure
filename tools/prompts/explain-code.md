# Prompt: Explain Code

Explain the following code clearly and concisely.

## Instructions
- Describe WHAT it does at a high level first (1-2 sentences)
- Then explain HOW it works, step by step
- Highlight any non-obvious logic or edge cases
- Point out potential risks or gotchas if any
- Keep the explanation at the level of a mid-level developer

## Do NOT
- Repeat the code back line by line
- Use jargon without explanation
- Over-explain simple constructs
